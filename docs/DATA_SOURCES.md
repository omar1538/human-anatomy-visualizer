# Data sources

Licences below are what the sources publish. **Re-read the licence page before using any model**
and record the result in `ATTRIBUTION.md`. If a licence is unclear, replace the model.

| Source | Content | Licence (as published) | Notes |
|---|---|---|---|
| BodyParts3D (DBCLS) | Anatomical meshes indexed by FMA identifiers | CC BY 4.0 on the project licence page; some repositories cite CC BY-SA | Only atomic parts have meshes; large raw download. Confirm in the Week 1 spike which sub-structures exist (e.g. heart chambers). |
| Z-Anatomy | Complete labelled body (Blender) | CC BY-SA 4.0, some models non-commercial | Derived from BodyParts3D. Check each model. Share-alike affects how we publish the asset pack. |
| HRA 3D Reference Object Library (NIH 3D) | Ready-to-use organs in GLB | CC BY 4.0 | Good for fast prototyping in Week 1. |
| TotalSegmentator dataset | CT scans with 117 segmented structures | CC BY 4.0 | **Stretch only.** Very large (about 23.6 GB total): download a handful of cases, never the whole set. |

## Rules
- Educational texts (function, facts, quiz questions) are **written by the team in its own words**,
  checked against a reliable reference. Do not copy textbook passages.
- Do not paste licensed textbook content into AI tools.
- If sources mix licences, the strictest one (share-alike) guides how the asset pack is published.
